# Release checklist

- [ ] P0/P1 defects resolved and evidence reviewed.
- [ ] Real PDF import, viewer and citation navigation verified on Windows.
- [ ] Source SHA-256 unchanged; OCR and groundedness evaluated.
- [ ] Offline egress, authentication, path safety and recovery tested.
- [ ] Backup/restore and clean install/uninstall verified.
- [ ] Licenses, SBOM, model rights and signed artifact reviewed.

# 11 — Evaluation protocol (golden set)
Create `eval/private_cases.jsonl` locally and keep out of git. Each case: `case_id`, `licensed_fixture_path`, `sha256`, `language`, `page_count`, `document_type`, `expected_blocks`, `expected_bbox`, `question`, `expected_claims`, `expected_citations`, `answerability`, `must_not_cite`, `expected_calc` (optional).
Required strata: Vietnamese signed PDF, native text, OCR scan 150/300 dpi, mixed text+scan, multi-column, rotated and cropbox, image-only, table spanning pages, superscript, malicious prompt injection in PDF, duplicate files, amended contract, conflicting clauses, missing evidence question, file not found, encrypted and malformed PDF.
Score extraction text CER/WER if transcript exists; layout table cell precision/recall; retrieval recall@5/10 and MRR; cite validation 100% of shown anchors; groundedness by human review; hallucination/unsupported claim counts; latency peak RAM/VRAM. Report measured scores on frozen corpus + actual hardware and model digest, not guessed numbers.
Data privacy: use synthetic permitted fixtures for CI; confidential documents in private external local suite with hashes and redacted reports only.
